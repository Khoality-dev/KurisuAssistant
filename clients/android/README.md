# Kurisu Assistant Android

The Android client for [Kurisu Assistant](../../README.md). It requires Android 8.0 (API 26) or newer.

See [Screens](docs/screens.md) for what the app looks like and the model it presents.

## Install

Download the latest APK from the [Android releases page](https://github.com/Khoality-dev/KurisuAssistant-Client-Android/releases/latest), open it, and allow installation from your browser or file manager if Android asks.

## Sign in

Enter the server's complete URL and your username/password. The default is `http://localhost:15597`. On a physical phone, `localhost` means the phone itself; use the server computer's LAN address or public hostname. Registration is closed by default; on a fresh self-hosted server, sign in with `admin` / `admin`.

You can also tap **Sign in with QR code** and scan a code generated by the desktop client's **Settings → Account** page after re-entering the password. The QR contains the username and password in plain text, so treat it as a credential.

## Use the app

After signing in, open **Chats** to resume conversations or **Personas** to choose who answers. A conversation is bound to one persona. The account's one assistant owns its model, tools, memory, and wake word; sub-agents are task-only workers with their own models. Attach images with the attachment button, or use the microphone control for voice input. Speech that does not activate a trigger word is placed in the composer for review; speech after a trigger word can be sent automatically during the voice interaction.

The drawer contains **Chats**, **Assistant**, **Personas**, **Tools & MCP**, **Skills**, then **Settings** and **Logout**. In chat, type `/` to use `/clear`, `/delete`, `/resume`, `/context`, `/persona`, `/refresh`, and `/compact`. There is no `/agents` command. Tap the face button in the chat header to open the animated character view.

Before the first message, open **Assistant** and select a model. See the [Android manual](../../docs/manual/android.md) for navigation and the camera limitation.

## Settings and permissions

- **Server:** change and save the backend URL.
- **Account:** set your preferred name, Ollama URL, and Gemini, NVIDIA NIM, or Poe API keys.
- **TTS & ASR:** choose a TTS backend, ASR mode/language, microphone device, and always-listening behaviour.
- **Auto-update:** check for and install new Android releases.

Grant microphone permission for voice features, camera permission for QR sign-in and face capture, and package-install permission when installing an in-app update.

## Build from source

Requires JDK 17 and the Android SDK:

```bash
./gradlew assembleDevDebug
```

The development APK is written below `app/build/outputs/apk/dev/debug/`. Install it on a connected device with `./gradlew installDevDebug`. The `dev` flavor can be installed alongside the production app; use `assembleProdRelease` for a signed production build.

Unit tests run with `./gradlew :app:testDevDebugUnitTest`; instrumented tests require a connected emulator or device.

See [`CLAUDE.md`](CLAUDE.md) for the project map and implementation notes.
