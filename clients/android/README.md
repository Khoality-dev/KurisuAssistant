# Kurisu Assistant Android

The Android client for [Kurisu Assistant](../../README.md). It requires Android 8.0 (API 26) or newer.

## Install

Download the latest APK from the [Android releases page](https://github.com/Khoality-dev/KurisuAssistant-Client-Android/releases/latest), open it, and allow installation from your browser or file manager if Android asks.

## Sign in

Enter the server's complete URL and your username/password. On a physical phone, `localhost` means the phone itself; use the server computer's LAN address or public hostname. You can also tap **Sign in with QR code** and scan a code generated by the desktop client's **Settings → Account** page. Treat login QR codes as passwords.

## Use the app

After signing in, the home screen lists your agents and conversations. Tap an agent to chat, attach images with the attachment button, or use the microphone control for voice input. Speech that does not activate a trigger word is placed in the composer for review; speech after a trigger word can be sent automatically during the voice interaction.

Use the navigation drawer to open **Agents**, **Tools & Skills**, **Settings**, and previous conversations. In chat, type `/` to use commands such as `/clear`, `/resume`, `/delete`, `/agents`, `/refresh`, `/context`, and `/compact`. Tap the face button in the chat header to open the animated character view.

## Settings and permissions

- **Server:** change and save the backend URL.
- **Account:** set your preferred name and Ollama URL. Provider API keys can be configured from the desktop client.
- **Text-to-Speech:** choose an available TTS backend and save it.
- **Speech Recognition:** set an ASR language and choose whether **Always Listen** keeps the microphone active.
- **Microphone:** select and test an input device.
- **Auto-update:** check for and install new Android releases.

Grant microphone permission for voice features, camera permission for QR sign-in and face capture, and package-install permission when installing an in-app update.

## Build from source

Requires JDK 17 and the Android SDK:

```bash
./gradlew assembleDevDebug
```

The development APK is written below `app/build/outputs/apk/dev/debug/`. Install it on a connected device with `./gradlew installDevDebug`. The `dev` flavor can be installed alongside the production app; use `assembleProdRelease` for a signed production build.

Unit tests run with `./gradlew :app:testDevDebugUnitTest`; instrumented tests require a connected emulator or device.

See [`CLAUDE.md`](CLAUDE.md) for the project map and implementation notes.
