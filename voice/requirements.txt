# one resolution, not three. What holds it together:

#     Whisper conversion any 4.x. huggingface_hub follows it (< 1.0).
#   - numpy 1.26: GPT-SoVITS is pinned < 2 upstream; everything else accepts it.
#   - coqui-tts (the maintained idiap fork, from PyPI) rather than the git fork
#     the viXTTS container built from; its two Vietnamese lines are applied at
#     load time in tts/vixtts_model.py.
# Unit tests need none of this: see requirements-ci.txt.
